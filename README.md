# E-commerce API-to-Warehouse Data Platform

A batch data engineering project that extracts catalog data from the Platzi
Fake Store API, generates synthetic order transactions, loads data into
PostgreSQL, transforms it with dbt, orchestrates workflows with Airflow,
and presents business metrics in Metabase.

## Project status

Current phase: Project initialization.

## Planned stack

- Python
- PostgreSQL
- dbt Core
- Apache Airflow
- Metabase
- Docker Compose
- pytest
- GitHub Actions

## Data sources

- Platzi Fake Store API
- Deterministic synthetic order generator
